# Local Recruiter/Public-Readiness FAQ

This FAQ is a non-technical inspection aid only. It explains the local
AsyncScholar status for recruiter/public-readiness review without publishing
anything and without changing the Gate E boundary.

It does not publish, release, expose, merge, or push the repository.

## What Is AsyncScholar?

AsyncScholar is a local-first lecture monitoring app for transcription, event
detection, alerts, archives, and study-review generation.

The current public-facing demo story is a fixture-to-reviewer demo. It shows a
safe local loop from fixture input through detected demo events, alert preview,
archive metadata, and reviewer-oriented output.

## What Is The Current Gate Status?

- Gate D / Product Promise Alpha: human-recorded narrow local fixture-to-reviewer
  pass only.
- Gate E: deferred and blocked on `human_gate_e_approval`.
- AI-solvable Gate E public-readiness reviews are complete and satisfactory as
  preparation work.
- Gate E is not approved.
- fresh human approval is still required before public release, public exposure,
  merge, push-to-main, publishing, or release.

## What Can A Reader Infer?

The local demo can show the fixture-to-reviewer loop:

- local fixture input
- completed session status
- detected demo events
- confirmation-required alert preview
- archive/reviewer metadata summary
- explicit safety boundaries

It cannot be used as proof of live online monitoring, real class or meeting
behavior, browser readiness, private-data readiness, production audio behavior,
or public release readiness.
